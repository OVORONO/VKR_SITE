# «Ростовская эмаль» — интернет-магазин ростовской финифти

Сайт мастерской ростовской финифти: каталог украшений, икон и сувениров с ручной росписью по эмали,
корзина, избранное, поиск и оформление заказа. Сделан как выпускная квалификационная работа,
сейчас поддерживается как проект для портфолио.

> **Демо-версия.** Магазин не настоящий: контакты условные, заказы и заявки никуда не отправляются.
> Это включается флагом `demoMode` в `data/site.json`.

## Что умеет сайт

- **Каталог** из 26 изделий с фильтрами по категории, материалу, коллекции и цене, сортировкой и счётчиками в фильтрах.
- **Страница каждого товара** со структурированными данными schema.org (Product, BreadcrumbList).
- **Поиск** с подсказками в шапке и отдельной страницей результатов.
- **Корзина и избранное** в `localStorage`: синхронизируются между вкладками, а цены всегда берутся из каталога,
  поэтому в корзине не устаревают.
- **Оформление заказа** с проверкой полей, нормализацией телефона и выбором доставки.
  Заказы сохраняются в разделе «Заказы на этом устройстве».
- **Формы** отправляются на `send.php` (PHP `mail()`). Если сервер недоступен, сайт предлагает отправить ту же заявку письмом.
- Адаптивная вёрстка, доступность (ARIA, фокус, `<dialog>`), локальные шрифты, WebP, `sitemap.xml`, `robots.txt`.

## Технические решения

- **Без фреймворков и сборщиков:** HTML, CSS и чистый JavaScript. Сайт открывается на любом хостинге,
  а для форм нужен только PHP.
- **Свой генератор статики на PowerShell.** `build.ps1` берёт общие блоки из `partials/` и данные из `data/*.json`, затем
  - подставляет шапку, футер и модальные окна во все страницы (между метками `<!-- @header -->` … `<!-- /@header -->`);
  - собирает карточки товаров на главной и в каталоге;
  - создаёт страницы товаров в `products/`;
  - пишет `site-data.js` (данные для поиска и корзины), `sitemap.xml` и `robots.txt`.

  Товары и контакты правятся в одном месте, а результат остаётся обычным статическим HTML,
  который хорошо индексируется.
- **Один источник данных:** каталог в `data/products.json`. Браузер получает его через сгенерированный `site-data.js`,
  поэтому карточки на страницах и в корзине не расходятся.

## Структура

| Что | Где |
| --- | --- |
| Страницы | `index.html`, `catalog.html`, `services.html`, `about.html`, `contacts.html`, `checkout.html`, `search.html`, информационные страницы, `404.html` |
| Страницы товаров | `products/*.html` (генерируются) |
| Стили | `common.css` (общие блоки) и по файлу на страницу |
| Скрипты | `site.js` (окна, меню, cookies, формы), `cart-favorites.js`, `search.js`, `catalog-filters.js`, `checkout.js`, `product.js` |
| Данные | `data/products.json` (товары), `data/site.json` (контакты, реквизиты, `demoMode`) |
| Шаблоны | `partials/` |
| Отправка форм | `send.php` |

## Как запустить

Посмотреть сайт можно через любой статический сервер из корня проекта:

```bash
npx http-server -p 8080
```

После правок в `partials/` или `data/` пересоберите страницы: двойной щелчок по `build.cmd`
или `powershell -File build.ps1`. Блоки между метками `@...` перезаписываются при сборке, руками их не правьте.

## Публикация

Загрузите на хостинг всё, кроме `partials/`, `build.ps1`, `build.cmd` и `README.md`.
В демо-режиме подойдёт GitHub Pages. Чтобы формы работали по-настоящему, нужен хостинг с PHP
и `"demoMode": false` в `data/site.json`, а также настоящие контакты и реквизиты там же.
