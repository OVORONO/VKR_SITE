# Сайт «Ростовская эмаль»

Статический сайт мастерской ростовской финифти: HTML, CSS и JavaScript без фреймворков.

## Как устроен проект

| Что | Где |
| --- | --- |
| Страницы | `index.html`, `catalog.html`, `services.html`, `about.html`, `contacts.html`, `delivery.html`, `returns.html`, `privacy.html`, `cookies.html`, `checkout.html`, `search.html`, `404.html` |
| Страницы товаров | `products/*.html` (создаются автоматически) |
| Общие стили | `common.css` (шапка, футер, карточки, окна, формы) |
| Стили страниц | `index.css`, `catalog.css`, `services.css`, `about.css`, `contacts.css`, `product.css`, `info.css` |
| Скрипты | `site.js` (окна, меню, cookies, формы), `cart-favorites.js` (корзина, избранное, заказы), `search.js` (поиск), `catalog-filters.js`, `checkout.js`, `product.js` |
| Товары | `data/products.json` |
| Контакты, реквизиты, соцсети | `data/site.json` |
| Общие блоки | `partials/` (шапка, футер, окна, карточка товара, шаблон страницы товара) |
| Отправка форм | `send.php` |
| Шрифты | `fonts/` (локально, без Google Fonts) |
| Старая версия сайта и исходные картинки | `_archive/` (на сервер не загружать) |

## Как вносить изменения

1. **Шапка, футер, корзина, контакты** — правьте файлы в `partials/` или `data/site.json`.
2. **Товары** — правьте `data/products.json`. Фото кладите в `images/products/` (лучше WebP, 800×800 px).
3. Запустите **`build.cmd`** (двойной щелчок). Скрипт обновит шапку и футер на всех страницах,
   карточки на главной и в каталоге, страницы товаров, `site-data.js`, `sitemap.xml` и `robots.txt`.

Блоки между комментариями `<!-- @header -->` и `<!-- /@header -->` (и другими `@...`) перезаписываются
при сборке — их содержимое руками не правьте. Всё остальное на страницах можно редактировать как обычно.

## Публикация

Загрузите на хостинг всё, **кроме** папок `_archive/`, `partials/` и файлов `build.ps1`, `build.cmd`, `README.md`.
Для работы форм нужен хостинг с PHP (Beget, Timeweb, REG.RU и т. п.). Без PHP формы предложат отправить заявку письмом.

## Что нужно заполнить перед запуском

- [ ] `data/site.json`: настоящие **телефон и e-mail** (сейчас шаблонные), **реквизиты** (ИП/ООО, ИНН, ОГРН/ОГРНИП, юр. адрес), **адрес сайта** (`siteUrl`), ссылка на канал **MAX** (пока иконка скрыта).
- [ ] `data/site.json`: номер счётчика **Яндекс.Метрики** (`yandexMetrikaId`) и код подтверждения **Яндекс.Вебмастера** (`yandexVerification`).
- [ ] `data/products.json`: **размеры** изделий (поле `size`), проверить **материалы** и **технику** («Уточняется» у четырёх товаров).
- [ ] Проверить, что «Северное сияние», «Розовый мрамор», «Мудрая сова» и «Яркая капля» действительно финифть.
- [ ] Сверить условия доставки, оплаты и возврата с реальными (сроки, службы доставки, способы оплаты) и показать юристу тексты `privacy.html`, `returns.html`, `delivery.html`.
- [ ] Новые фото товаров в высоком разрешении, несколько ракурсов, фото на модели, фото упаковки.
- [ ] После переезда на HTTPS — раскомментировать редирект в `.htaccess`.
